# Albina Galgame Card

Pure CDN deployment root for the SillyTavern independent frontend card.

Import script:

```js
import 'https://cdn.jsdelivr.net/gh/q18718859808-sketch/albina-galgame-card@v1.0.0/dist/albina-galgame-card/console/index.js'
```

The root contains the runnable `dist/` package, card files, accepted image assets, presets, regex scripts, scenes, and pure worldbook packs.
