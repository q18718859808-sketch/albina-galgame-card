# Install

Use the v1.0.20 CDN import:

```js
import 'https://cdn.jsdelivr.net/gh/q18718859808-sketch/albina-galgame-card@v1.0.20/dist/albina-galgame-card/console/index.js'
```

Do not publish runtime imports pinned to `main`, `master`, or `latest`. The deploy report records a commit-pinned import after each release.
